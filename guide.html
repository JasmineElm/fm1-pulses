FM-1 Pulses guide

← back to the app

Everything on this page is one control from the app and one line for what it does. The whole tool is: shape the settings, generate a bank of 16 patterns, freeze the good ones into the FM-1's own sequencer.

Bank

Seed number

One number, everything derives from it. Same seed plus same settings gives the same bank. Change it and the whole bank changes.

Drift 0–100%

How much the 16 slots differ from each other. 0% means they share the same settings and differ only by luck. 100% means slot 1 and slot 16 are far apart.

Pitch

Scale

The note set the melody snaps to. Pentatonic minor is the safe default.

Root 24–84, as a note

The tonic the scale is built on. This is the key, not where the melody sits.

LFO wave

What makes the pitch move. sine, triangle, saw and square are fixed contours. random draws a fresh value from the Spread distribution. The other three are older random shapes.

Amplitude 0–100%

How far notes reach above and below the Offset note. 0% is one note. 100% is ±18 semitones.

Unipolar checkbox

Off, notes spread both ways around the Offset note. On, the Offset note becomes the floor and notes only rise from it.

Offset −100 to +100%

The centre of the pitch range. Amplitude spreads evenly around this note. This is where the melody lives.

LFO cycles 1–16

How many times the pitch contour repeats across the phrase. Whole numbers repeat predictably. Fractional values like 16.5 drift, so each pass lands somewhere new.

Octave up 0–100%

Chance a note jumps up one octave. The jump is 12 semitones, which is the same scale degree, so it stays in key. The jump is written into the note, so the FM-1 plays it too.

Root gravity 0–100%

Chance a note is pulled to the nearest root note. It keeps its register, so the melody gets grounded instead of flattened onto a single pitch.

Density

Gate 0–100%

Chance each step plays a note. 0% is silence, 100% is every step. This is the rhythm.

Grid snap 0–100%

Chance a note is kept only if it lands on a grid line. 0% leaves the rhythm fully random, 100% keeps only the grid lines. Notes off the grid become rests. Gate decides how many of those lines fire, so density and grid work together.

Snap grid 2–8 steps

Spacing of the grid lines, in steps. 4 is one beat at 1/16, which gives quarter notes. 2 gives eighth notes. Odd values like 3 and 5 do not divide the bar, so they land lopsided and drift across the phrase.

Velocity 1–127

Base loudness. Only the browser and live MIDI hear it; the FM-1 plays its own velocity on pattern playback.

Humanize 0–100%

Random per-note velocity wobble, ±40 at 100%. Same caveat as Velocity.

Character

Spread

The distribution the notes come from. constant is one pitch, bell weights the centre, uniform is flat, extremes only hits the two ends. Matters most with the random wave.

Bias −100 to +100

Tilts the distribution low (−) or high (+) without changing the range. Not a pitch shift, a likelihood shift.

Quantize 0–100%

How hard notes snap to the scale. 100% is always in scale. Lower lets chromatic passing notes through.

Memory

Loop 2–32 steps

Motif length. The first N steps repeat across the phrase, filling up to Length. The slider reaches half the pattern length, and odd values are allowed, so you can loop 7 or 9 steps. If Loop is half of Length or more there is nothing to fill, so it does nothing.

Deja Vu 0–100%

Chance a step past the motif copies the motif instead of playing its own note. 0% plays the phrase as generated, 100% repeats the motif to the end. In between, fresh notes bleed in.

Pattern header (written into the FM-1)

Note value

The length of one step, which sets the bar length. At 1/32 a 64-step phrase is 2 bars; at 1/16 it is 4 bars.

Tempo 30–300 BPM

Playback speed, in the header and in the audition.

Gate length 5–100%

How long each note holds. Low is staccato, high is legato.

Swing 50–75%

Delays every other step. 50% is straight, 75% is triplet (2:1). Heard in the audition and written to the pattern.

Length 1–64 steps

How many of the 64 steps the pattern plays.

Workflow

1. Connect the FM-1 and pick it in the device list.

2. Set Scale, Root, Offset, and Amplitude. Hit Generate.

3. Tap through the 16 slots. Keep the ones you like.

4. Freeze → FM-1 writes one slot, Send all 16 writes the bank.

5. Unplug it and the FM-1 plays on its own.

Stop the FM-1's sequencer before freezing. It refuses a write while its sequencer is playing and answers with status 3. Press SEQ off. STOP alone is not enough.
