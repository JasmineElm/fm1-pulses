FM-1 PULSES

guide

Every control on the panel, what it does, and a thing to try. The shape of it: set the settings, generate a pattern, freeze it into the FM-1's own sequencer. ← back to the panel

Reading the panel

Knobs and switches

Round knobs are continuous: drag up and down, use the wheel, or the arrow keys. Double-click resets to the default. sine-style switches are rotary: one detent per option, and the chosen name prints underneath.

Transport

Randomise rolls settings and derives a fresh pattern from a new random seed (R or G). Play loops the pattern so you can tweak it live. The sound switch picks the browser preview timbre (e-piano, bell, bass, organ, square); the FM-1 plays its own patch when frozen. Freeze writes the pattern, Clear wipes the FM-1's sequencer. The strip at the bottom picks the theme. Freeze needs the FM-1+VA / Baud Girl firmware — the pattern-write SysEx only exists there; on stock firmware the app works as a live MIDI broadcaster (▶ Play).

The pattern display

The 64-step grid sits eight wide by eight deep. Tap a step to edit it: − and + move it a semitone, ✕ empties it. Any step you touch is locked, so it survives regeneration. When the loop is on, the tiled region is tinted in the accent colour (its first step a notch brighter) in the grid.

Presets / export / import

save ▸ / ◂ load slots 1–5

Five local preset slots under the transport keep banks in the browser. Tap a slot to recall it; double-click to overwrite it; or arm save ▸ / ◂ load and then tap. A preset holds everything an export file does: the knobs, the seed, the locked steps.

export file

Downloads the current state as JSON: every knob, the seed, and the locked steps. The pattern derives from the seed, so the file is the song — anyone who imports it gets the identical pattern.

import file

Loads a JSON file exported from FM-1 Pulses. Parameters are validated and clamped, the pattern regenerates from the file's seed, and locked steps come back as they were.

sysex file

Downloads the pattern as a .syx file — the raw SysEx pattern-write messages, so any other FM-1 tool can push the same pattern to the device without the browser.

Bluetooth

bluetooth link

Connects the FM-1 over BLE MIDI for cable-free playback: the ▶ Play loop sends its notes over Bluetooth. Freeze, Clear and the device-BPM read still need USB — on this firmware BLE carries notes and controllers only; the pattern SysEx does not ride it (verified on hardware). If the link drops, the app reconnects on its own and shows bluetooth … in the link.

Global

Tempo 30–300 BPMknob

Playback speed for the browser player. The FM-1's BPM is device-global and cannot be set over MIDI — this firmware acks the tempo bytes of a pattern write and discards them. Freezing therefore does not change the device's BPM; the unit's own tempo governs standalone playback. After every freeze (and on connect) the app reads the device's real BPM and snaps this knob to it, so what you see is what the device plays.

Pattern button

Randomises the pattern and seed (R or G) to instantly generate a new melodic contour and rhythm.

Note dropdown

Step note rate (1/16, 1/8, 1/4, triplets, etc.) governing sequence playback speed relative to BPM.

Length 1–64 stepsknob

Pattern length in steps. Active steps light up in the 16×4 grid; steps beyond Length are dimmed and muted.

Gate length 5–100%knob

How long each note holds as a percentage of step time. Low is staccato, high is legato. Applied globally across all sequencers.

Rhythm

16×4 Step Grid & Rhythm Controls panel

A full-width step sequencer with a dedicated button for all 64 steps, arranged into a 16×4 grid (four 16-step bars). Each bar is grouped into 4-step beats with downbeat indicators. Tap any step to toggle its gate on or off. When playing, a live playhead tracks across the grid.

Euclid: Select from classic world rhythms (Tresillo, Cinquillo, Son/Rumba Clave, Bossa Nova, Soukous, Samba, Gahu, Aksak, Bembé) or specify custom Hits (N), Division (M), and Blend (random 0% to even Euclidean spacing 100%), with a fast Rnd override checkbox.
Snap: Probability (0–100%) and grid interval (2–8 steps) that filters notes to land on grid lines.
Rotate: Shift the pattern steps cyclically with ◀ and ▶.
Batch Tools: All On, All Off (clear gates), Invert (flip all gates), and Random (stochastically rolls gates using current density).

Humanise

Humanize 0–100%fader

Adds subtle micro-timing jitter to make playback feel human and organic. Includes fast groove pills: Tight (0%), Subtle (20%), Loose (45%), Wild (80%).

Swing 50–75%fader

Delays every other step. 50% is straight, 75% is triplet (2:1). Includes quick presets: Straight (50%), Light (54%), MPC (58%), Hard (66%), Triplet (75%). Available across all sequencer models, heard during live playback, and written into FM-1 pattern memory.

Global

Randomise button

Rolls fresh parameters and generates a new pattern from a new random seed. Press R or G to roll at any time.

Note value

The length of one step, which sets the bar length. At 1/32 a 64-step phrase is 2 bars; at 1/16 it is 4 bars.

Length 1–64 stepsknob

How many of the 64 steps the pattern plays.

Quantize 0–100%knob

How hard notes snap to the scale. 100% is always in scale. Lower lets chromatic passing notes through.

Unipolar switch

Off, notes spread both ways around the Offset note. On, the Offset note becomes the floor and notes only rise from it.

Pitch

Wave switch

What makes the pitch move. sine, tri, saw and sqr are fixed contours. perlin is a smooth coherent contour — long evolving arcs, not white noise. random draws a fresh value from the Spread distribution. walk, smooth and hold are the older random shapes.

Shape 0–100%knob

Morphs the wave. On sine it drives the sine into a wavefolder (harmonically richer arcs); on tri and saw it bends the ramp into a curve; on sqr it narrows the pulse width from 50% to 5%; on perlin it adds a detuned octave shimmer; on walk it widens the step size; on smooth it speeds the slew. At 0% every wave is its classic self.

Cycles 1–16knob

How many times the contour repeats across the phrase. Whole numbers land on the phrase and repeat; fractional values drift, so every pass differs.

Amplitude 0–100%knob

How far notes reach above and below the Offset note. 0% is one note. 100% is ±18 semitones.

Offset −100 to +100%knob

The centre of the pitch range. Amplitude spreads evenly around this note. This is where the melody lives.

Scale switch

The note set the melody snaps to. Pentatonic minor is the safe default.

Root 24–84, as a noteknob

The tonic the scale is built on. This is the key, not where the melody sits.

Shape

Spread switch

The distribution notes come from. constant is one pitch, bell weights the centre, uniform is flat, extremes only hits the two ends. Bites hardest on the random wave.

Bias −100 to +100knob

Tilts the distribution low or high without changing the range. Not a pitch shift, a likelihood shift.

Humanize 0–100%knob

Random per-note velocity wobble, ±40 at 100%. Only the browser player hears this; the FM-1 plays its own velocity.

Velocity 1–127knob

Base loudness for the browser player. Same caveat as Humanize.

Octave up 0–100%knob

Chance a note jumps up one octave. Twelve semitones is the same scale degree, so it stays in key. The jump is written into the note, so the FM-1 plays it too.

Root gravity 0–100%knob

Chance a note is pulled to the nearest root note. It keeps its register, so the melody gets grounded instead of flattened onto one pitch.

Memory

Loop from step 1 … Length−2knob

Where the repeated region starts. Everything before it is an intro that plays once.

Loop len 2 … the rest of Lengthknob

How long that region is. Together with Loop from it tiles, say, steps 13 to 29 out to the end of the phrase.

Deja Vu 0–100%knob

Chance a step past the loop copies the loop instead of playing its own note. 0% plays the phrase as generated, 100% repeats the region to the end. The readout in the display shows the region and how many repeats fit, and copied steps are marked in the grid with a dashed ring — the region itself sounds once, so those marks begin one region after Loop from.

Workflow

1. Connect the FM-1. The LED lights when it is found.

2. Choose a scale, root note, and timbre. Hit Randomise (or press R/G) to roll a pattern.

3. Audition and tweak the pattern live with ▶ Play.

4. Freeze writes the pattern into the FM-1.

5. Unplug it and the FM-1 plays on its own.

Stop the FM-1's sequencer before freezing. It refuses a write while its sequencer is playing. Press SEQ off. STOP alone is not enough.
