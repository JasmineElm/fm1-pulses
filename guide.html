FM-1 PULSES

guide

High-level guide to the FM-1 Pulses generative workstation: select an algorithmic sequencer model, shape musical phrases, audition in real time, and freeze patterns into the M-VAVE FM-1's hardware memory. ← back to panel

Workflow

1. Select Model: Choose an engine from the landing hub (or click ‹ models in the status bar).

2. Connect Device: Plug the FM-1 in via USB. The status LED turns green when Web MIDI connects.

3. Shape & Audition: Tweak parameters or press Randomise (R / G). Click ▶ Play (Space) to audition through the browser synth and FM-1.

4. Freeze: Press Freeze (F) to write the pattern into the FM-1. Stop device playback first.

Stop device sequencer before freezing: The firmware rejects pattern writes (status 3) while playing. Turn SEQ off on the FM-1 before freezing.

Sequencer Models

Mene311 Stochastic S&H

Analog-inspired generative signal chain. Gate probability triggers Sample & Hold and continuous LFO waveshaping, shaped through Gaussian distributions, quantized across musical scales, and repeated via a looping Deja-Vu buffer.

Turing Machine Shift Register

Probabilistic melody generator inspired by Music Thing Modular. A circulating loop of bits slips and mutates according to write probability, shifting between locked loops and evolving melodic drift.

Cellular Automata Wolfram 1D Rules

Step matrix driven by 1D elementary cellular automata (Rules 30, 90, 110, 150). Contours evolve across successive generations through local neighbor interactions, yielding organic self-similar patterns.

Particles Kinetic Collision Grid

2D multi-head particle simulator inspired by Orca and Plinky. Autonomous playheads traverse an interactive grid, rebounding off boundaries and deflectors. Note events trigger on collision (deflect, bounce, spawn, or annihilate).

Shared Workstation Architecture

Global & Transport

▶ Play loops the sequence for live performance and tweaking. Randomise rolls new seeds and parameters. Tempo sets playback speed; on connect and after freezing, the app reads the FM-1's hardware BPM over USB and snaps this value. Length (1–64 steps), Note rate, and Gate length apply across all models.

Notes & Scale Quantizer

Every model feeds into a central quantization engine. Select from 20 musical scale presets or build a custom scale using the chromatic grid. Set the Root tonic note, adjust Quantize snap intensity, and expand register using Octave Span and direction modes.

Rhythm & 16×4 Step Grid

Dedicated 64-step interface in four 16-step bars with live playhead tracking. Tap any step to toggle its gate. The Euclid engine provides instant world rhythm presets (Tresillo, Clave, Bossa Nova, etc.) and algorithmic hit/division blending, plus grid snap and rotation tools.

Groove & Dynamics

Humanize introduces micro-timing jitter for organic feel. Swing delays alternate steps, featuring instant groove presets (Straight, Light, MPC, Hard, Triplet) auditioned live and written into FM-1 pattern memory. Velocity sets base loudness and optional randomization.

Pattern Display & Step Locking

Interactive pitch matrix for direct step editing: adjust semitones, clear steps, or lock steps. Locked steps (🔓) survive regeneration and randomization, serving as manual anchors while patterns evolve.

Tools

DX Patch Generator 6-OP FM Voice & Bank Design

Algorithmic sound designer and SysEx patch manager for Yamaha DX7 and FM-1 hardware. Generate patches across 11 sonic categories (Keys, Bass, Pads, Leads, Bells, etc.), mutate sounds with controlled drift, edit operator ratios/levels/envelopes, audition with an internal 6-OP FM synth, and send directly to FM-1 hardware over USB MIDI or export 32-voice .syx banks.

Connectivity & Portability

USB & Bluetooth MIDI

USB MIDI provides full two-way communication: pattern freezing, device BPM sync, and live note streaming. Bluetooth (BLE) MIDI enables wireless playback auditioning (freezing and hardware reads require USB).

Presets & Files

Five internal memory slots (save ▸ / ◂ load) store workstation states in browser storage. export and import save and restore complete state as reproducible JSON files. sysex downloads raw .syx pattern files for external flashing tools.

Firmware Compatibility

Pattern freezing (SysEx 0x20) requires the FM-1+VA / Baud Girl custom firmware. On stock firmware, FM-1 Pulses functions as a real-time generative MIDI performance broadcaster.
